# 阿拾 · 桌面宠物 · 使用说明

一只住在 Windows 桌面上的小宠物。它会**看你屏幕**，跟你一起吐槽、一起看剧、
一起打游戏 —— 不是那种等你下指令的助手。

---

## 一、第一次用（三步）

1. **解压到一个可写的目录**，比如 `D:\阿拾`。
   ⚠️ 别放 `C:\Program Files` —— 它会在自己旁边建 `config.json`、`memory\` 等文件，
   那些目录默认没写权限。

2. **双击 `JarvisLite.exe`。** 桌面上会出现一只小狐狸（默认形象）。

3. **右键托盘图标 → 设置 → API**，填 API Key。

> 不填 Key 它也能启动，但只会说一句「右键我 → 设置，填 API Key 就能聊了」。

---

## 二、模型必须能「看图」（最重要的一步）

阿拾的核心是**看你屏幕**，所以必须选一个**支持图片输入**的模型。

填成纯文本模型**不会崩**，但它会变成瞎子 —— 接口会直接返回：

```
Model xxx does not support image input. Remove the image content or use a vision-capable model.
```

### 推荐（都验证过）

| 接口 | base_url | 模型名 |
|---|---|---|
| **DeepSeek 官方**（最便宜） | `https://api.deepseek.com/v1` | `deepseek-flash` |
| 硅基流动（实测最快） | `https://api.siliconflow.cn/v1` | `Qwen/Qwen3-VL-8B-Instruct` |
| 智谱 BigModel | `https://open.bigmodel.cn/api/paas/v4` | `glm-4.5v` |
| 通义千问 / 百炼 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen3-vl-plus` |
| Kimi | `https://api.moonshot.cn/v1` | `kimi-k3` |

**只填一个就够**：`模型` 填上面的视觉模型，`看图模型` 留空
（留空 = 聊天和看图共用同一个）。

也可以拆开省钱：`模型` 填便宜的纯文本模型负责聊天，`看图模型` 填视觉模型专门看图。

### 别填这些（看不见屏幕）

- `deepseek-v4-pro` —— DeepSeek 家只有 `deepseek-flash` 支持视觉
- `deepseek-chat` / `deepseek-reasoner` —— 老一代模型名

## 三、怎么用它

### 桌宠本体

| 操作 | 效果 |
|---|---|
| 左键拖动 | 挪位置。松手后位置会记住，下次启动还在那儿 |
| 双击 | 开关「看屏幕」（关掉它就不瞄你屏幕了）|
| 右键 | 弹出菜单（和托盘菜单同一个）|
| 拖到屏幕边 | **超过一半出屏**才会缩起来藏好；没超过一半就停在原地（算你自己放的）。鼠标靠过去自动露出来 |

### 托盘图标

| 菜单项 | 作用 |
|---|---|
| 对话 (Ctrl+M) | 打开对话面板。Enter 发送，Shift+Enter 换行 |
| 历史记录 | 看对话流水账 |
| 桌宠归位 | 找不到了就点它 —— 回到右下角完整可见处 |
| 设置 | API / 基本设置 / 外观 / 数据 四个页签 |
| 阿拾记住了什么 | 看它攒下的「关于你的事」，可以直接改 |
| 修复托盘图标 | 托盘图标没了/点不动时点它 |
| 退出 | 关掉它（**会优雅退出**，不留幽灵图标）|

> 左键**点一下**托盘图标也能唤出对话面板。

## 四、它记着什么

打开设置 → **数据** 页，或者从历史记录窗口看：

| 记的东西 | 说明 |
|---|---|
| **对话记录** | 按天的聊天流水，用来当聊天上下文 |
| **长期记忆** | 它攒下的「关于你这个人」的事实 —— **每天沉淀一次**：把前一天聊过的 + 在屏幕里看到的，一起提炼进去。可以直接改 |
| **今日足迹** | 今天干了什么、每项**花了多久**（离开电脑不算），每天归档 |

三个都可以在窗口里手动清空（会先弹确认，防误触）。

---

## 五、文件都在哪

全在 exe 旁边：

| 文件 / 目录 | 内容 |
|---|---|
| `config.json` | 你的设置，**含 API Key**（别外传）|
| `memory\YYYY-MM-DD.json` | 当天的对话记录 |
| `user_memory.md` | 长期记忆 |
| `activity\history.md` | 今日足迹的档案 |
| `log.txt` | 每次弹气泡说了什么 |
| `ui_log.txt` | 被拦下的话（排查用）|
| `crash.log` | 崩了的话这里有调用栈 |
| `shots\` | 最近几张屏幕截图（只在开了看屏幕时有）|

## 六、常见问题

**Q：托盘点不动了？**
右键**桌宠本体** →「修复托盘图标」。还不行就点「桌宠归位」。

**Q：它不说话 / 说的都是「看不见屏幕」之类？**
基本是模型填错了 —— 回去看第二节，确认填的是**支持图片输入**的模型。

**Q：在游戏里看不见它？**
独占全屏的游戏盖不住，这是 Windows 的规则，任何普通窗口都不行。
把游戏显示模式改成**「无边框」/「窗口化全屏」**就能正常浮在上面。

**Q：杀毒软件报警？**
PyInstaller 打的包偶尔会被误报。它不联网做别的事，只调你配的那个 API。

**Q：想让它安静点？**
设置 → 外观 里有气泡显示时长；开屏幕感知的间隔在「基本设置」里。
也可以直接双击桌宠关掉感知。

**Q：怎么卸载？**
退出程序（托盘 → 退出），把整个文件夹删掉就行。它不写注册表、不装服务。
想留着配置就把 `config.json` 和 `user_memory.md` 拷出来。

---

## 七、想换形象？

设置 → 外观 → 形象，内置 4 套立绘 + 2 套矢量形象。

也支持**外部素材**：往 exe 旁边的 `assets\` 里丢
`pic_自定义名_idle.png`（可选 `_blink.png` / `_talk.png`），
重启设置面板就能在列表里看到，不用重新打包。
