# assets/ — 立绘（图片素材）形象

## 命名规则

每套立绘最多三帧，放在本目录下，PNG 带透明通道：

```
<base>_idle.png    必须，站立静止帧
<base>_blink.png   可选，闭眼帧（眨眼时切到这一帧）
<base>_talk.png    可选，张嘴帧（说话时切到这一帧）
```

- 只有 `_idle.png` 也能用，另外两帧会自动退回 idle。
- 也可以只放一张 `<base>.png`（不带后缀），会被当作 idle。
- 三帧**建议用同一张图改眼睛/嘴巴**（图生图），保证姿势一致，否则换帧时会跳动。

## 想再加一套

1. 把三帧 PNG 按上面的命名放进本目录；
2. 在 `pet.py` 的 `Pet.IMAGE_SKINS` 里加一条 `("名字", "<base>", "<缺图时退回的矢量形象>")`；
3. 重开设置面板，下拉里就会出现。**素材不存在时该条目不会显示**，所以不会选到空形象。
