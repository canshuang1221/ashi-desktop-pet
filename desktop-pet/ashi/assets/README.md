# assets/ — 立绘（图片素材）形象

## 命名规则

每套立绘最多三帧，放在本目录下，PNG 带透明通道：

```
<base>_idle.png    必须，站立静止帧
<base>_blink.png   可选，闭眼帧（眨眼时切到这一帧）
<base>_talk.png    可选，张嘴帧（说话时切到这一帧）
```

- 只有 `_idle.png` 也能用，另外两帧会自动退回 idle。
- 也可以只放一张 `<base>.png`（不带后缀），会被当作 idle。
- 三帧**建议用同一张图改眼睛/嘴巴**（图生图），保证姿势一致，否则换帧时会跳动。

## 生成流程（见 `../tools/`）

1. `tools/sf_img.py` —— 调硅基流动生图。第一帧（睁眼）用 **Kwai-Kolors/Kolors**，
   便宜且快（约 5 秒）。
2. 第二、三帧用 **Qwen/Qwen-Image-Edit-2509** 改眼睛/嘴巴，保证和第一帧是同一只角色
   （实测：可图换 seed 或改提示词都保不住角色一致性，必须走图像编辑）。
   ⚠️ 这个编辑模型约 **0.3 元/张**，且要 60~90 秒，**只在必要时用**。
3. `tools/local_frames.py` —— **零成本替代方案**：直接对第一帧做像素处理生成闭眼/张嘴帧
   （把眼睛区域垂直压扁 + 在嘴的位置画开口）。眼睛坐标是手写的，换素材时先跑
   `preview()` 看框位。
4. `tools/key_art.py` —— 抠背景 + 三帧对齐，产出本目录的 `<base>_*.png`。

## 抠图的几个坑（都已在脚本里处理）

- **不能用 `ImageDraw.floodfill` 抠这套图的背景**：它是拿种子色做比较的，
  粉色渐变背景从角落到画面中部色差就超阈值了，泛洪中途停住，两侧大片背景删不掉。
  改用「按与背景色的距离全局删」。
- **阈值要卡准**：背景自身色距在 15 以内；角色粉色鼻头约 27、腮红约 42、
  奶白毛 66 以上。取 **16** 最稳；鼻头和腮红被误删后用「小洞填回」补上。
- **模型会在角色脚下画一片粉色地面阴影**，它比背景深、色距不够近，
  靠 `(R-B>10) & (G<R-15)` 这个粉色调判据在最下方一条带里单独删掉。
- **多帧一定要逐帧归一化**，别让三帧共用同一个裁剪框：图像编辑生成的帧，
  角色整体尺寸和原帧可能差好几个百分点（实测毛绒小兽那套：睁眼帧高 977px、
  眯眼帧只有 903px），共用裁剪框会让换帧时角色忽大忽小。
  正确做法是各自缩放到同一高度、按**前景质心**水平对齐（比包围盒中心抗噪）、
  底边对齐同一基线 —— 见 `tools/key_art.py` 的 `place()`。

## 想再加一套

1. 把三帧 PNG 按上面的命名放进本目录；
2. 在 `pet.py` 的 `Pet.IMAGE_SKINS` 里加一条 `("名字", "<base>", "<缺图时退回的矢量形象>")`；
3. 重开设置面板，下拉里就会出现。**素材不存在时该条目不会显示**，所以不会选到空形象。
